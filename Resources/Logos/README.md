# Logos and artwork

Logos and the background artwork are trademarks of their owners and are **not** part of the open-source code.
Place the files here before building (or drop them on Settings → Branding in the app):

| File name | Content |
|---|---|
| `germany.(png|jpeg)` | Partner logo 1 |
| `hungary.(png|jpeg)` | Partner logo 2 |
| `enam.png` | Partner logo 3 |
| `scalefree-white.png` | Maintainer logo (white, for the dark footer) |
| `background-lowcontrast.png` | Window background (low-contrast artwork) |

Without these files the app shows the partners' names as text and a plain background.
Use of the Fulbright marks is governed by the Fulbright Visual Identity Standards.
